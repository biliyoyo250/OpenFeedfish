从哪里复制？

在已登录的 DeepSeek 充值页按 F12，打开 Application → Local Storage → https://platform.deepseek.com，复制 userToken 的完整值（可直接复制 JSON）。也可从 Network 中 users/current 请求的 Request Headers 复制 Authorization。只粘贴在本页，不要发到聊天；无需反复复制刷新后变化的 Cookie。

Harness 授权（备用）

在可信设备的项目目录运行 npm run connect-account，打开显示的本机链接，再使用已登录浏览器授权。官方页面标注 DeepSeek Harness；也可下载独立助手后使用 Node.js 运行。
